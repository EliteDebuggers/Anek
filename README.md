# Anēk | Ek Se Anēk - Community Civic Network

Anēk (अनेक) is India's community-driven, reward-based platform for civic action. The philosophy is simple: one person ('Ek') taking initiative can inspire a wider community ('Anēk').

This platform empowers citizens to take charge of their neighborhoods, report local issues, collaborate with neighbors, and earn rewards (Good Citizen Points - GCP) for driving real change.

## Features

- **Report Problems:** Log local issues (water logging, road damage, illegal dumping) with a map pin and photographic evidence.
- **Local Impact Feed:** View active issues in your area and track their resolution status.
- **Civic Rewards:** Earn GCP for reporting and resolving issues. Redeem GCP for community garden passes, coffee credits, and more.
- **Contribution Log & Leaderboard:** Track your personal impact and see how you rank among other community leaders.

## Tech Stack

- HTML5, Vanilla JavaScript
- Tailwind CSS
- Vite

## How to Run Locally

1. **Install dependencies ( initial setup ) :**
   You need to have Node.js and `pnpm` installed. go to the `frontend` directory and run:
   ```bash
   pnpm install
   ```

2. **and to the server:**
   ```bash
   pnpm run dev
   ```

3. **and in browser:**
   Go to the local URL that u see in your console (usually `http://localhost:5173/` or `http://localhost:5174/`) in your web browser.
